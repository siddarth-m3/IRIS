<h2>Project Overview</h2>

<p>
This project presents a complete machine learning workflow using the classic Iris dataset.
The goal is to classify iris flowers into three species based on their physical measurements.
</p>

<p>
It covers exploratory data analysis, preprocessing, feature scaling,
model training, hyperparameter tuning, and evaluation.
</p>

</div>
