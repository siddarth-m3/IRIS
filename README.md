<h1 align="center">🌸 Iris Flower Classification</h1>

<p align="center">
A simple machine learning project to classify iris flowers based on their measurements.
</p>

<hr>

<h2>About the Project</h2>

<p>
This project explores the famous Iris dataset and builds machine learning models 
to classify flowers into three species based on sepal and petal measurements.
</p>

<p>
The goal of this project is to understand the complete machine learning workflow,
from data exploration to model evaluation.
</p>

<hr>

<h2>Dataset Information</h2>

<p><strong>Target Classes:</strong></p>
<ul>
  <li>Iris-setosa</li>
  <li>Iris-versicolor</li>
  <li>Iris-virginica</li>
</ul>

<p><strong>Features Used:</strong></p>
<ul>
  <li>Sepal Length</li>
  <li>Sepal Width</li>
  <li>Petal Length</li>
  <li>Petal Width</li>
</ul>

<hr>

<h2>Project Workflow</h2>

<ol>
  <li>Data loading and inspection</li>
  <li>Exploratory Data Analysis (EDA)</li>
  <li>Data preprocessing and feature scaling</li>
  <li>Train-test split</li>
  <li>Model training</li>
  <li>Hyperparameter tuning</li>
  <li>Model evaluation</li>
</ol>

<hr>

<h2>Models Implemented</h2>

<ul>
  <li><strong>Gaussian Naive Bayes</strong></li>
  <li><strong>Logistic Regression</strong> (with GridSearchCV tuning)</li>
  <li><strong>Support Vector Machine (SVM)</strong></li>
</ul>

<hr>

<h2>Evaluation Metrics</h2>

<ul>
  <li>Accuracy Score</li>
  <li>Confusion Matrix</li>
  <li>Precision, Recall, and F1-Score</li>
</ul>

<hr>

<h2>Technologies Used</h2>

<p>
Python, NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn
</p>
